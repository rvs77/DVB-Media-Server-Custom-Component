# Politica di sicurezza

Non segnalare problemi di sicurezza tramite issue GitHub pubbliche.

Finché non sarà disponibile un canale privato dedicato, segnalare una possibile vulnerabilità al proprietario del repository tramite i meccanismi di contatto privati disponibili su GitHub.

Indicare la versione interessata, i passaggi per riprodurre il problema e le eventuali mitigazioni sicure individuate. Non includere password, token, registrazioni o altri dati personali.
