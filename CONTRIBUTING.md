# Contributing

Thank you for helping improve this independent integration.

Please open an issue before a substantial change, keep changes focused, and
include tests for parsing or behaviour that changes. Never include credentials,
private IP addresses, recordings, channel lists, DMS configuration exports, or
copyrighted DVBViewer material in an issue, pull request, fixture or screenshot.

By contributing, you confirm that you may license your original contribution
under this repository's MIT License.
