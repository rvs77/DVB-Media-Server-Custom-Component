# Contribuire al progetto

Grazie per contribuire al miglioramento di questa integrazione indipendente.

Prima di una modifica sostanziale, aprire una issue per descrivere la proposta. Mantenere le modifiche focalizzate e aggiungere test quando cambia il comportamento o il parsing dei dati.

Non includere mai credenziali, indirizzi IP privati, registrazioni, liste canali, esportazioni della configurazione DMS o materiale DVBViewer protetto da copyright in issue, pull request, fixture o screenshot.

Contribuendo al progetto, si conferma di poter distribuire il proprio contributo originale secondo la licenza MIT di questo repository.
