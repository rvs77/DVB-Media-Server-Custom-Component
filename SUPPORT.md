# Supporto

Utilizzare GitHub Issues per segnalare bug riproducibili dell'integrazione e GitHub Discussions, quando disponibile, per domande d'uso e proposte.

Per licenze, installazione, supporto del prodotto o problemi propri di DVBViewer Media Server, rivolgersi ai canali ufficiali DVBViewer. Questo progetto non è un canale di supporto ufficiale per i prodotti DVBViewer.
