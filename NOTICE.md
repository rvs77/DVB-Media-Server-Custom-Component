# Avvisi relativi a terze parti

## DVBViewer Media Server

Questo progetto interagisce con la Web API di DVBViewer Media Server. Non contiene, distribuisce, modifica, decompila, effettua reverse engineering o deriva dal software DVBViewer o DVBViewer Media Server.

I nomi "DVBViewer" e "DVBViewer Media Server" sono utilizzati esclusivamente per identificare il prodotto di terze parti compatibile. Possono essere marchi dei rispettivi titolari. Questo repository non concede alcuna licenza per utilizzare marchi, loghi, binari, codice sorgente, testi della documentazione, registrazioni, liste canali o credenziali di licenza di terze parti.

## Home Assistant e HACS

Questo progetto è una custom integration indipendente. Non è un'integrazione ufficiale Home Assistant, non è certificato "Works with Home Assistant" e non utilizza i loghi Home Assistant o HACS. "Home Assistant" e "HACS" possono essere marchi dei rispettivi titolari.

## Privacy e materiale di supporto

I dati diagnostici possono includere metadati dei canali e titoli delle registrazioni. Credenziali, host configurato, percorsi dei file e cartelle di registrazione vengono oscurati. Prima di pubblicare una segnalazione o un pacchetto diagnostico, l'utente deve comunque verificare e rimuovere eventuali informazioni private o personali.
